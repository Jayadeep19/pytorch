# pytorch
- A collection of hands-on implementations covering the fundamentals of Machine Learning and Deep Learning using PyTorch, starting from scratch up to neural network architectures.

## 🛠️ Tech Stack
- Language: Python
- Framework: PyTorch, numpy
- Environment: Jupyter Notebooks

## 🚀 Getting Started
To explore or run the notebooks locally:
```bash
# Clone the repository
git clone https://github.com/Jayadeep19/pytorch.git

# Navigate into the directory
cd pytorch

# Install requirements (PyTorch, Jupyter, etc.)
pip install torch torchvision jupyter
```
or run the notebooks in google colab after cloning the repo
